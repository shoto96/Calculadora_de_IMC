# 📊 Calculadora de IMC

Aplicação web simples e responsiva para cálculo do Índice de Massa Corporal (IMC), com feedback visual e interface moderna.

---

## 📄 Sobre

O **IMC (Índice de Massa Corporal)** é uma métrica utilizada para avaliar se o peso está adequado em relação à altura.

**Fórmula:**

```
IMC = peso (kg) / altura² (m)
```

---

## 📊 Classificação

| IMC         | Resultado      |
| ----------- | -------------- |
| < 18,5      | Abaixo do peso |
| 18,5 – 24,9 | Peso ideal     |
| 25,0 – 29,9 | Sobrepeso      |
| 30,0 – 34,9 | Obesidade I    |
| 35,0 – 39,9 | Obesidade II   |
| ≥ 40        | Obesidade III  |

---

## ✨ Funcionalidades

* Cálculo automático do IMC
* Feedback visual por categoria
* Barra indicadora de resultado
* Validação de dados
* Layout responsivo (mobile e desktop)
* Tema escuro moderno
* Animações suaves

---

## 🚀 Como usar

1. Clone o repositório:

```bash
git clone https://github.com/seuusuario/calculadora-imc.git
```

2. Abra o arquivo `index.html` no navegador

3. Informe:

* Peso (kg)
* Altura (m)

4. Clique em **Calcular**
